# Workflow: AI-search discoverability

## Procedure

1. Identify the organization's real identity, offerings, projects, terminology, and target audiences from verified sources.
2. Check whether key facts are available in crawlable HTML.
3. Improve page clarity: explicit definitions, useful headings, descriptive project pages, and direct answers to genuine user questions.
4. Ensure organization/project facts are consistent across pages and structured data.
5. Research current official crawler documentation for each relevant platform.
6. Separate search/retrieval crawler decisions from training crawler decisions.
7. Review robots, CDN/WAF, and server behavior. Do not infer blocking from one failed request.
8. Consider optional `llms.txt` or Markdown indexes only if maintainable and useful; explain that these do not guarantee visibility.
9. Define realistic measurement and monitoring.
10. Record all changes and unresolved uncertainties.

## Completion criteria

- Important facts are clear, accurate, and accessible.
- Crawler decisions are documented and approved.
- No visibility or ranking guarantees are made.
