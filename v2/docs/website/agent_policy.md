# Agent Skill Usage Policy

## 1. Skill Discovery

Before starting a website-related task:

- Inspect the available skills.
- Identify relevant skills for the requested task.
- Read the applicable skill instructions before implementation.
- Do not assume a skill is available without verifying its location and contents.

## 2. Cognika Website Skills

Use the following skills according to the task:

### Cognika Design Skill
Mandatory for significant visual design changes.

Purpose:
- Preserve Cognika's visual identity.
- Maintain design consistency.
- Guide the dark, space-inspired visual language.
- Preserve the blue accent and existing branding.
- Prevent unrelated design directions.

### Anthropic Frontend Design
Use when designing or implementing frontend pages and components.

### UI UX Pro Max
Use when working on:
- Navigation.
- Page structure.
- User journeys.
- Responsive layouts.
- Interaction design.

### Vercel Web Design Guidelines
Use when reviewing or implementing:
- Frontend quality.
- Accessibility.
- Performance.
- Semantic HTML.
- Responsive behavior.

### GSAP
Use only when a task requires animation or advanced motion.

Do not introduce GSAP unnecessarily when CSS animations are sufficient.

## 3. Skill Selection Rules

1. Do not load every available skill for every task.
2. Select skills based on the actual task.
3. The Cognika Design Skill takes priority for brand-specific design decisions.
4. General frontend skills must not override Cognika's established visual identity.
5. When two skills provide conflicting recommendations, identify the conflict and follow the project documentation.
6. Do not install additional skills or dependencies without approval.

## 4. Implementation Reporting

For significant tasks, report:

- Which skills were selected.
- Why they were selected.
- Whether their instructions were followed.
- Any conflicts or missing capabilities.

Skills provide expertise and implementation guidance; they do not authorize changes to production, authentication or project architecture.
