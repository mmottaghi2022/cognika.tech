COGNIKA homepage concept

Files
- index.html: page structure and menu content
- styles.css: visual design, circular navigation, responsive styling, stars and animated meteors
- script.js: hover/focus/click behavior for the orbit menu and central panel

How to preview
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Hover over a circular menu item (or tab to it using the keyboard) to change the central panel.

Deployment
Upload the three files to your web host's public web directory (often public_html or www).
No build tools are required. The page is a static front-end concept; project pages, real contact details,
and download URLs should be connected before a production launch.

Note: Google Fonts are loaded remotely when internet access is available. The design falls back to
system fonts when unavailable.
